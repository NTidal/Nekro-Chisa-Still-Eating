# 千小妹还在吃 (Chisa Still Eating) — NekroAgent 版

跨次元干饭摇号群聊娱乐插件。移植自 AstrBot 插件
[astrbot_plugin_chisa_still_eating](https://github.com/dddada123/astrbot_plugin_chisa_still_eating) v4.2.3
（原作者 **Rua432**，MIT 协议）。

版本：**4.2.3-na**。

---

## 功能与完成度

**群聊玩法（直连触发，不消耗 LLM）——已全部实装**
- 🎲 多世界盲盒摇号：`吃什么 / 喝什么 / 来点黑暗料理`，权重随机 + 群维度防重历史（连续不重样）
- 🌍 定向打卡：`来点现实的食物`、`鸣潮特产`、`原神特饮` 等锁定世界/卡池
- 👑 羁绊召唤：`召唤爱弥斯下厨`、`弗洛洛特供料理`、`想和XX吃饭`，锁定厨师并附立绘
- 🥷 防刷屏：滑动窗口限频、复读摆烂冷却、干饭人随机截胡彩蛋
- 👨‍🍳 群内图库管理：`加菜 [世界] [分类] [菜名]`（带图）、`上传厨师 [名]`（带图），支持多图
- 🛒 千小妹商会：60 秒交互菜单、目录同步、`进货/招募/黑魔法召唤[编号]` 一键下载 DLC
- ☁️ 基础图库一键拉取：`更新千小妹图库`（约 99.2MB，四镜像测速 + 直连兜底 + SHA-256 校验 + 安全解压）
- 🎭 导游情绪表情包（like/think/speechless/scared）、厨师立绘（GIF 优先）、干饭人 `words.txt` 语录
- 三种抽取模式（忠诚/摇号机/现充）、群黑/白名单、管理员白名单

**WebUI 管理大屏（NekroAgent 插件页打开，无独立端口）——已全部实装**
- 🗂️ 图库管理：食物/饮品/黑暗料理/厨师立绘/情绪表情/干饭人的浏览、批量上传、单菜命名、重命名、删除；
  干饭人招募（语录 + 多图）与语录编辑
- 🛒 网页版千小妹商会：官方云仓与第三方创意工坊（GitHub 仓库地址）目录同步、封面拉取、
  商品一键进货、已购清单、工坊书架
- 🎨 皮肤工坊：官方/第三方皮肤源订阅（最多 5 个）、皮肤索引、毛玻璃/纯色主题切换、
  背景 192KiB 分块下载、毛玻璃模糊度调节、本地皮肤删除
- 🐾 **吉祥物自定义**（见下节）：右下角立绘随机图片池 + 随机点击文案
- 网络安全：逐跳 HTTPS 主机白名单、镜像节点测速、响应大小上限、SHA-256 校验、ZIP 安全解压；
  WebUI 内进货/上传/删除即时刷新摇号缓存

**未实装项及原因**
- **OneBot 合并转发**：NekroAgent 段消息体系无合并转发原语，长帮助/商品列表以普通长文本发送，
  功能内容不缺失。
- **AI 拟人播报**：原版该功能依赖 AstrBot 宿主 LLM 的事件回调机制，NekroAgent 插件侧无等价挂点；
  所有播报改用内置文案模板池（`templates.json` / `worlds.json`，可自定义），故不提供对应配置项。

## 安装

1. 将 `chisa_eating/` 目录放入 NekroAgent 插件目录，或在 NA WebUI 上传发布包 zip。
2. **完全重启 NekroAgent**：直连消息钩子、FastAPI 路由与 WebUI 均在启动时挂载，热重载不生效。
3. 在插件配置 **「管理员账号白名单」** 填入你的平台 ID（QQ 号），否则无法使用群内管理指令。
4. 群里发送 `更新千小妹图库`（需管理员），等待约 99.2MB 基础图库自动下载解压；
   过程中可发 `千小妹图库下载进度` 查看。网络不佳时按 `千小妹帮助` 中的网盘链接手动部署：
   - 夸克：https://pan.quark.cn/s/301110d45a48
   - 百度：https://pan.baidu.com/s/1ZHfYz8vNL5JU0jyFtHiYqQ?pwd=erm9
   - 解压后把 `food/`、`drink/`、`chefs/` 等文件夹放进插件数据目录，再发 `千小妹重载`。
5. 打开 WebUI：NekroAgent WebUI → 插件 → 「千小妹还在吃」管理页（地址形如
   `/plugins/Rua432.chisa_eating/__webui__/webui.html`）。

## 指令速查（群聊）

| 指令 | 说明 | 权限 |
| --- | --- | --- |
| `吃什么` / `喝什么` / `来点黑暗料理` | 全宇宙摇号 | 所有人 |
| `来点现实的食物` / `鸣潮特产` / `原神特饮` | 锁定卡池/世界 | 所有人 |
| `召唤[厨师]下厨` / `[厨师]特供料理` / `想和XX吃饭` | 锁定厨师（附立绘） | 所有人 |
| `千小妹帮助` / `千小妹速查` | 帮助菜单 | 所有人 |
| `千小妹商会` | 60 秒进货交互菜单（回复 1/2/3） | 管理员 |
| `千小妹商会信息同步` | 拉取最新商品目录 | 管理员 |
| `进货[编号]` / `招募[编号]` / `黑魔法召唤[编号]` | 下载官方 DLC（如 `进货fd0001`） | 管理员 |
| `更新千小妹图库` / `千小妹图库下载进度` | 基础图库拉取 / 进度查询 | 管理员 |
| `加菜 [世界] [分类] [菜名]`（同条消息带图） | 群内加菜，如 `加菜 鸣潮 饮品 冰吸生椰拿铁` | 管理员 |
| `上传厨师 [厨师名]`（带图） | 添加厨师立绘 | 管理员 |
| `千小妹重载` | 手动放图/改 JSON 后刷新缓存 | 管理员 |

> 摇号类指令均为**直连触发**（绕过 LLM 直接回复）。若长句子里提到「吃什么」也会抢话，
> 开启配置 **「仅精确/短消息触发摇号」**（见下表）。

## 配置项说明

在 NekroAgent 插件配置页修改。概率项为 0–100 的整数；权重为相对权重，**无需加起来等于 100**。

### 权限
| 配置 | 默认 | 说明 |
| --- | --- | --- |
| 管理员账号白名单 `ADMIN_USERS` | 空 | 平台 ID（QQ 号）列表，每行一个；命中者可用商会/加菜/更新图库/重载等管理指令。留空则无人可用管理指令（WebUI 不受此限） |

### 触发词
| 配置 | 默认 | 说明 |
| --- | --- | --- |
| 吃什么触发词 `TRIGGER_EAT` | 吃什么/吃啥/吃点儿啥 | 子串命中即触发全宇宙美食摇号，每行一个，可自定义 |
| 喝什么触发词 `TRIGGER_DRINK` | 喝什么/喝啥/喝点儿啥 | 同上 |
| 黑暗料理触发词 `TRIGGER_DARK` | 来点黑暗料理 | 整活：奇怪菜名 + 黑暗配图 |
| 现实食物触发词 `TRIGGER_COMMON_EAT` | 来点现实的食物/来点三次元食物 | 只抽三次元/现实卡池 |
| 现实饮品触发词 `TRIGGER_COMMON_DRINK` | 来点现实的饮品/来点三次元饮品 | 同上 |

### 卡池权重（相对权重）
| 配置 | 默认 | 说明 |
| --- | --- | --- |
| 三次元/现实权重 `WEIGHT_COMMON` | 70 | 现实外卖卡池 |
| 世界1（鸣潮）权重 `WEIGHT_W1` | 20 | |
| 世界2（原神）权重 `WEIGHT_W2` | 5 | |
| 世界3（终末地）权重 `WEIGHT_W3` | 5 | |
| 世界4（自定义）权重 `WEIGHT_W4` | 0 | 默认无图库，自行加菜后再调大 |

### 摇号行为
| 配置 | 默认 | 说明 |
| --- | --- | --- |
| 防重历史长度 `HISTORY_LIMIT` | 30 | 每群记住最近多少道菜不重复，0 关闭 |
| 防刷屏阈值 `SPAM_THRESHOLD` | 3 | 60 秒内点菜超过该次数触发导游吐槽拦截 |
| 干饭人截胡概率 `EGG_PROB` | 10% | 摇号结果被干饭人抢走的彩蛋概率 |
| 厨师立绘概率 `CHEF_MEME_PROB` | 50% | 召唤厨师时附带立绘的概率 |
| 导游表情包概率 `GLOBAL_MEME_PROB` | 30% | 摇号时附带主活动世界导游表情的概率 |
| 拦截时截胡概率 `INTERCEPTION_EGG_CHANCE` | 50% | 被防刷屏拦截时干饭人抢饭概率 |
| 复读摆烂概率 `REPEAT_PROB` | 10% | 导游学用户说话/摆烂概率 |
| 复读冷却 `REPEAT_COOLDOWN` | 60 秒 | 同群两次复读最短间隔 |
| 指定干饭人卡池 `EGG_POOL` | 空 | 留空全部随机；只让部分干饭人出场时填名字，分号分隔 |
| 主活动世界 `ACTIVE_WORLD` | 世界1(鸣潮) | 决定导游自称、情绪表情包、忠诚模式卡池 |
| 配菜表情包转 GIF `CONVERT_MEME_TO_GIF` | 开 | QQ 下渲染为小表情气泡；需 Pillow，失败回退原图 |
| 忠诚模式 `MODE_LOYAL` | 关 | 只抽主活动世界 + 三次元 |
| 摇号机模式 `MODE_ROLLER` | 关 | 排除三次元卡池 |
| 现充模式 `MODE_NORMIE` | 关 | 只抽三次元卡池 |

### 聊天黑白名单
| 配置 | 默认 | 说明 |
| --- | --- | --- |
| 启用群黑名单 `ENABLE_BLACKLIST` / `BLACKLIST_CHATS` | 关 / 空 | 命中的群完全不响应，填群号或 chat_key，每行一个 |
| 启用群白名单 `ENABLE_WHITELIST` / `WHITELIST_CHATS` | 关 / 空 | 仅命中的群响应 |

### 直连触发灵敏度
| 配置 | 默认 | 说明 |
| --- | --- | --- |
| 仅精确/短消息触发摇号 `EXACT_TRIGGER_ONLY` | 关 | 开启后摇号玩法只在「去标点/@/英文数字后字符数 ≤ 阈值」的短消息直连回复；更长的自然口语放行给主 Agent。商会/加菜/帮助等精确匹配指令不受影响。关=子串命中即直连 |
| 摇号触发最大字数 `TRIGGER_MAX_LEN` | 10 | 上一项开启时生效，中文按字符计 |

### WebUI 吉祥物
| 配置 | 默认 | 说明 |
| --- | --- | --- |
| 点击吉祥物随机切换 `MASCOT_CLICK_SWITCH` | 开 | WebUI 右下角吉祥物：数据目录 `mascots/` 放多张图后点击随机切换；关闭则点击只弹文案气泡 |

## WebUI 吉祥物自定义

点击页面顶部「🐾 吉祥物」打开设置面板：

- **随机图片池**：上传多张图片（GIF/PNG/JPG/WebP，单张 ≤8MB，自动按文件魔数校验格式、重名自动编号），
  点击右下角吉祥物即随机切换一张（尽量不连续重复）；池为空时显示内置千小妹立绘。
  面板内可看缩略图、单张删除。图片存于数据目录 `mascots/`，也可手动往该文件夹放图后
  在 WebUI 刷新或重开面板生效。
- **随机文案**：文本框内一行一句，点「保存文案」后，点击吉祥物随机弹出；
  留空则使用内置 6 条千小妹语录。文案存于数据目录 `mascot_quotes.txt`（UTF-8）。
- 顶部「毛玻璃」滑块（0–100，映射 0–20px）调节背景虚化力度，「保存」随皮肤偏好持久化。

## 数据目录结构

可写数据均在插件数据目录 `Rua432.chisa_eating/`（**不要**写进插件安装目录）：

```
food/{common,world1..world4}/    # 食物图；文件名【厨师名】菜名.png 触发专属立绘
drink/{...}/                     # 饮品图
darkfood/{...}/                  # 黑暗料理图
chefs/                           # 厨师立绘（厨师名.jpg，GIF 优先）
memes/<world>/{like,think,speechless,scared}/   # 导游情绪表情包
ganfanren/<干饭人名>/            # 截胡表情包 + words.txt（一行一句语录，utf-8/gbk 均可）
mascots/                         # WebUI 吉祥物随机图片池
mascot_quotes.txt                # 吉祥物点击随机文案（一行一句，留空用内置）
worlds.json                      # 世界名称/别称/自称池/句式（首次启动从内置默认生成）
templates.json                   # 全局文案模板池（首次启动生成）
group_history.json               # 防重历史（自动维护）
Webui-PIC/
├── Shop/index/{catalog,metadata,downloaded}.json   # 官方商会缓存
├── Workshop/<仓库>/{index,cover}/                  # 第三方工坊缓存、书架 _bookmarks.json
├── banner/                                         # 商店/工坊横幅
└── skins/                                          # 皮肤工坊数据（源订阅、偏好、缓存背景）
```

- 自定义文案/世界：编辑 `worlds.json`（各世界句式/别称/自称）与 `templates.json`（全局模板），
  改完发 `千小妹重载`（WebUI 上传操作会自动刷新）。
- 手动加干饭人：在 `ganfanren/` 下建文件夹（如 `佩可莉姆/`），放表情包 + `words.txt` 即自动入列。
- 图片命名：`【厨师名】菜名_序号.png` 解析为厨师羁绊菜；普通名 `菜名.png` 为普通菜。

## WebUI 其他说明

- 页面为文件型 WebUI，随插件包分发（`webui.html` + `banner.jpg` / `hello.jpg` / `Chisa.gif`），
  接口走插件路由下 `/api/*`，图片以 base64 data URL 传输，无二进制路由。
- 第三方工坊/皮肤源只接受 **GitHub 仓库地址**（`https://github.com/作者/仓库` 或 `作者/仓库`），
  下载仅允许 GitHub / jsDelivr / 白名单镜像域名，逐跳校验 HTTPS。
- 内置皮肤（`maple_dew`、`yy_xuanling`、`chisa_red_black`、`chisa_red_white`）仅来自官方源且不可删除。
